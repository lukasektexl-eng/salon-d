# Salon Dominique – ukázkový návrh webu

Neoficiální ukázkový návrh nového webu pro Salon Dominique – Best for Body (Říčany).
Čisté HTML + CSS + vanilla JS, bez build kroku – funguje přímo na GitHub Pages.

- `index.html`, `style.css`, `script.js`
- `assets/` – logo a fotografie salonu (WebP)

Rezervace je pouze DEMO a nic neodesílá.
